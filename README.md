# Персональний помічник

Консольний застосунок для адресної книги та особистих нотаток. Дані
зберігаються локально й не губляться після перезапуску.

## Вимоги та запуск

Потрібен Python 3.10 або новіший. Сторонніх залежностей немає.

```bash
python3 main.py
```

Після запуску меню показується один раз. Вводьте команди, доки не введете
`exit` або `close`.

Файл даних створюється у папці користувача:

```text
~/assistant_data.pkl
```

Не відкривайте сторонні `.pkl`-файли: `pickle` можна використовувати лише для
даних, яким ви довіряєте.

## Команди контактів

| Команда | Що робить |
| --- | --- |
| `add-contact` | Інтерактивно створює контакт: ім’я, телефон, email, адресу та день народження. Порожній Enter пропускає необов’язкове поле. |
| `find-contact <запит>` | Шукає за частиною імені, UUID, телефону, email, адреси або дати народження. |
| `change-contact <UUID або запит>` | Знаходить контакт, пропонує обрати поле та змінити `name`, `phone`, `email`, `address` або `birthday`. |
| `delete-contact <UUID або запит>` | Показує контакт і видаляє його тільки після відповіді `yes`. |
| `birthdays <дні>` | Показує контакти, чий найближчий день народження настане за вказану кількість днів. `0` дозволено. |

Контакти мають UUID, тому кілька людей можуть мати однакове ім’я. Якщо пошук
дає кілька результатів, програма покаже UUID і попросить вибрати конкретний.

### Валідація контакту

- Ім’я не може бути порожнім.
- Телефон: рівно 10 цифр або міжнародний формат `+` і від 10 до 15 цифр.
  Пробіли, дужки й дефіси ігноруються.
- Email має формат на кшталт `name@domain.tld`.
- День народження вводиться як `DD.MM.YYYY`.

Некоректне значення показує повідомлення та не закриває застосунок.

## Команди нотаток

| Команда | Що робить |
| --- | --- |
| `add-note` | Додає нотатку з непорожнім текстом. |
| `find-note <запит>` | Шукає текст у нотатках без урахування регістру. |
| `change-note <UUID>` | Замінює текст нотатки. |
| `delete-note <UUID>` | Видаляє нотатку тільки після `yes`. |

Кожна нотатка також має UUID, який програма показує після створення.

## Теги нотаток

| Команда | Що робить |
| --- | --- |
| `add-tag <UUID> <тег>` | Додає тег до нотатки. |
| `edit-tag <UUID> <старий> <новий>` | Замінює тег. |
| `delete-tag <UUID> <тег>` | Видаляє тег після підтвердження `yes`. |
| `show-notes-by-tag <тег>` | Показує нотатки з тегом. |
| `sort-notes-by-tags` | Виводить усі нотатки, відсортовані за тегами. |

Теги нормалізуються: `#Work`, `work` і ` WORK ` — це один тег `work`.

## Підказка команд

Якщо команда введена з помилкою або скорочено, програма пропонує найближчу
команду, але не виконує її автоматично:

```text
find-co
Unknown command. Did you mean: find-contact?
```

## Структура

```text
main.py                 цикл CLI і маршрутизація команд
contact_commands.py     сценарії роботи з контактами
note_commands.py        сценарії роботи з нотатками та тегами
models.py               Contact, Note і валідація полів
books.py                AddressBook і NotesBook
upcoming_birthdays.py   обчислення найближчих днів народження
storage.py              збереження та завантаження даних
command_suggester.py    підказка для невідомих команд
```

`Contact` містить одне значення для телефону, email, адреси й дня народження.
`Note` містить текст і множину тегів. `AddressBook` та `NotesBook` зберігають
ці сутності за UUID; обидва успадковують `UserDict`.
